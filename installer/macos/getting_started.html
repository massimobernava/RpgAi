Welcome to RpgAi

An AI-powered interactive story engine. Choose your adventure, talk to characters, shape the world.

Quick start

1

RpgAi is already running. Switch to the browser tab that opened alongside this page — that is the game interface.

2

By default, RpgAi uses Ollama local · free — an AI that runs entirely on your Mac with no internet or API key required. If Ollama is installed and a model is loaded, you can play immediately.

3

In the game interface: pick a script, enter your character name, and start playing. Use the Settings panel (⚙ icon) to change the AI provider or load a save.

Open RpgAi →
