Welcome to RpgAi

This installer will:

  • Install the rpgai command-line tool
  • Create your story workspace at ~/Documents/RpgAi/
  • Copy default Lua scripts and Python servers

Your workspace will contain:

  • scripts/ — Lua story scripts and libraries
  • servers/ — Python servers (text-to-image, TTS, NPC)
  • output/ — generated content
  • saves/ — saved sessions
